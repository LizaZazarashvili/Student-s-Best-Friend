# Student's Best Friend

A responsive, single-page landing site for a fictional AI study companion, styled like a welcoming library café.

## Run locally

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript; it has no build step or framework. Google Fonts and the hero photograph load from external URLs, so those assets require an internet connection.

## What's included

- Responsive navigation with a mobile menu
- About, three study feature cards, contact form, and footer
- Client-side contact form feedback (no message is sent or stored)
- Keyboard focus styles, a skip link, and reduced-motion support

## Files

- `index.html` — semantic page structure and content
- `style.css` — layout, responsive styles, and visual design
- `script.js` — mobile navigation and contact form interaction
